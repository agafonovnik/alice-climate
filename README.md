# Алиса Климат

Температура и влажность из «Дома с Алисой» в строке меню macOS.

Выбор комнаты, обновление раз в минуту и статус датчиков. Токен хранится в Связке ключей macOS.

## Сборка

Нужны macOS 13+ и Xcode Command Line Tools (`xcode-select --install`).

```sh
./build.sh
```

Готовое приложение: `dist/Алиса Климат.app`. Скрипт собирает версию для архитектуры текущего Mac и подписывает её локально.

## Подключение

Создайте приложение в [Яндекс OAuth](https://oauth.yandex.ru/) типа «Для доступа к API или отладки» с разрешением `iot:view`. В настройках «Алиса Климат» укажите ClientID, получите токен и подключите аккаунт.
